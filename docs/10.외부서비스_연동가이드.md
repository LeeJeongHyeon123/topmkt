## 2. 알리고 SMS API 설정

### 🚀 실제 SMS 발송을 위한 알리고 계정 설정

Mock 모드를 제거하고 **실제 문자 발송**을 위한 완전한 설정 가이드입니다.

#### 📝 2.1 회원가입
1. **알리고 웹사이트 접속**: https://smartsms.aligo.in
2. **회원가입** 클릭
3. 필요 정보 입력:
   - 회사명: 탑마케팅
   - 담당자명: [실제 이름]
   - 연락처: [실제 전화번호]
   - 이메일: [실제 이메일]

#### 🔑 2.2 API 키 발급
1. **로그인** 후 **마이페이지** → **API 관리**
2. **API 키 발급** 요청
3. **API 키**와 **사용자 ID** 확인 및 복사

#### 📞 2.3 발신번호 등록
1. **마이페이지** → **발신번호 관리**
2. **발신번호 등록** (예: [실제 번호])
3. **인증 절차** 완료 (SMS 인증)
4. **승인 대기** (보통 1-2일 소요)

#### 🔧 2.4 프로젝트 설정 업데이트

`src/config/config.php` 파일을 다음과 같이 수정:

```php
// 알리고 SMS API 설정
define('ALIGO_API_KEY', '[발급받은_API_키]');           // ⚠️ 실제 키로 변경
define('ALIGO_USER_ID', '[사용자_ID]');                  // ⚠️ 실제 ID로 변경
define('ALIGO_SENDER', '[등록된_발신번호]');             // ⚠️ 실제 번호로 변경
define('ALIGO_API_URL', 'https://apis.aligo.in/send/');
define('ALIGO_REMAIN_URL', 'https://apis.aligo.in/remain/');

// SMS 실제 모드 설정
define('SMS_MOCK_MODE', false);                          // 항상 실제 발송
define('SMS_TEST_PHONE', '[테스트_전화번호]');           // 테스트용 전화번호
```

> **⚠️ 보안 주의**: API 키와 발신번호는 반드시 실제 값으로 변경하세요. GitHub에 업로드 금지!

#### 💰 2.5 SMS 충전
1. **마이페이지** → **충전하기**
2. 필요한 만큼 충전:
   - SMS (단문): 건당 약 20원
   - LMS (장문): 건당 약 50원
   - MMS (그림문자): 건당 약 200원

#### ✅ 2.6 테스트 실행

모든 설정이 완료되면 다음 명령어로 **실제 문자 발송** 테스트:

```bash
# 1. 빠른 테스트 (즉시 발송)
curl -k -X GET "https://www.topmktx.com/sms/test/quick"

# 2. 웹 테스트 페이지 접속
브라우저에서: https://www.topmktx.com/sms/test
```

**성공 시 응답 예시:**
```json
{
    "success": true,
    "message": "SMS 발송이 완료되었습니다.",
    "data": {
        "result_code": "1",
        "message": "success",
        "msg_id": "202410181234567890",
        "success_cnt": 1,
        "error_cnt": 0,
```

## 3. reCAPTCHA v3 설정

### 🔐 reCAPTCHA v3란?

reCAPTCHA v3는 Google의 최신 보안 서비스로, 사용자 상호작용을 분석하여 봇과 인간을 구별합니다. 기존의 체크박스나 이미지 선택 없이 백그라운드에서 자동으로 작동합니다.

### 📋 3.1 현재 적용 상태 (v3.89.7)

탑마케팅 프로젝트에는 reCAPTCHA v3가 적용되어 있습니다:

```
사이트 키 (공개): [Google reCAPTCHA 콘솔에서 확인]
비밀 키 (서버): [보안상 문서에 기재 안 함 - 서버 설정 파일 참조]
도메인: www.topmktx.com
```

> **🔥 보안 중요**: 비밀 키는 절대 GitHub이나 공개 문서에 포함하지 마세요!

### 🚀 3.2 적용된 기능

#### 회원가입 보안
- SMS 인증번호 발송 시 reCAPTCHA 검증
- 회원가입 폼 제출 시 reCAPTCHA 검증
- 점수 기반 필터링 (0.5 이상만 허용)

#### 스팸 방지
- SMS 발송 Rate Limiting (1분당 3회 제한)
- 봇 탐지 및 차단
- 의심스러운 활동 로깅

### 📁 3.3 구현된 파일들

#### 클라이언트 사이드
```javascript
// src/views/auth/signup.php 내 스크립트
- reCAPTCHA v3 라이브러리 로드
- 토큰 생성 및 폼 제출
- 에러 처리 및 사용자 피드백
```

#### 서버 사이드
```php
// src/controllers/AuthController.php
- verifyRecaptcha() 메서드
- SMS 발송 및 회원가입 시 검증
- 점수 기반 승인/거부 로직
```

### 🔧 3.4 새 프로젝트 설정 방법

만약 새로운 도메인이나 프로젝트에서 reCAPTCHA를 설정해야 한다면:

#### Google reCAPTCHA 콘솔 접속
1. https://www.google.com/recaptcha/admin 접속
2. Google 계정으로 로그인

#### 새 사이트 등록
1. "+" 버튼 클릭하여 새 사이트 추가
2. 라벨: 프로젝트 이름 입력
3. reCAPTCHA 유형: "reCAPTCHA v3" 선택
4. 도메인: 실제 도메인 입력 (예: example.com)
5. 소유자: 이메일 주소 추가
6. reCAPTCHA 서비스 약관 동의
7. "제출" 클릭

#### 키 확인 및 복사
- 사이트 키와 비밀 키가 생성됨
- 이 키들을 안전한 곳에 저장

#### 코드에 키 적용

**AuthController.php 수정**
```php
private function verifyRecaptcha($token, $action) {
    // ⚠️ 비밀 키는 환경 변수나 설정 파일에서 읽어오세요
    $secretKey = getenv('RECAPTCHA_SECRET_KEY');

    // 나머지 코드는 동일
}
```

**signup.php 수정**
```html
<script src="https://www.google.com/recaptcha/api.js?render=새로운_사이트_키"></script>
<script>
grecaptcha.ready(function() {
    window.recaptchaSiteKey = '새로운_사이트_키';
});
</script>
```

## 4. Firebase Realtime Database 설정

### 🔥 Firebase Realtime Database란?

Firebase Realtime Database는 실시간 NoSQL 클라우드 데이터베이스로, 데이터가 변경되면 연결된 모든 클라이언트에 즉시 동기화됩니다.

### 📊 4.1 탑마케팅 활용 사례 (v3.7.0)

#### 실시간 채팅 시스템
- 1:1 채팅 메시지 저장
- WebSocket 기반 실시간 메시지 전달
- 읽음 상태 실시간 업데이트

#### 실시간 알림 시스템
- 강의/행사 신청 대기 알림
- 30초 폴링 → 실시간 푸시 (99.7% 지연 시간 개선)
- 서버 요청 100% 감소

### 🔧 4.2 Firebase 프로젝트 설정

#### 1. Firebase 프로젝트 생성
1. https://console.firebase.google.com 접속
2. "프로젝트 추가" 클릭
3. 프로젝트 이름 입력 (예: topmkt-project)
4. Google 애널리틱스 설정 (선택사항)

#### 2. Realtime Database 활성화
1. 좌측 메뉴에서 "Realtime Database" 선택
2. "데이터베이스 만들기" 클릭
3. 위치 선택: asia-southeast1 (싱가포르)
4. 보안 규칙: 잠금 모드로 시작 (나중에 수정)

#### 3. 웹 앱 추가
1. 프로젝트 설정 → 일반 → "웹 앱 추가"
2. 앱 닉네임 입력 (예: topmkt-web)
3. Firebase SDK 구성 코드 복사

#### 4. 보안 규칙 설정
```json
{
  "rules": {
    "pendingRegistrations": {
      "$userId": {
        ".read": "auth != null && auth.uid == $userId",
        ".write": "auth != null"
      }
    },
    "chat": {
      "$chatId": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
```

### 📁 4.3 프로젝트 통합

#### 서버 사이드 (PHP)

**FirebaseHelper.php**
```php
// src/helpers/FirebaseHelper.php

```

#### 클라이언트 사이드 (JavaScript)

**Firebase 초기화**

## 5. Firebase Cloud Messaging (FCM) 설정

### 📱 FCM이란?

Firebase Cloud Messaging(FCM)은 무료로 메시지를 안정적으로 전송할 수 있는 크로스 플랫폼 메시징 솔루션입니다.

### 🎯 5.1 탑마케팅 FCM 활용 (v3.89.0)

#### 구현된 9가지 푸시 알림 시나리오

1. ✅ **댓글 알림** - 내 게시글에 댓글 작성 시
2. ✅ **대댓글 알림** - 내 댓글에 답글 작성 시
3. ✅ **좋아요 알림** - 내 게시글에 좋아요 클릭 시
4. ✅ **채팅 메시지 알림** - 1:1 채팅 메시지 수신 시 (필수 알림)
5. ✅ **신규 강의 알림** - 새로운 강의 등록 시
6. ✅ **신규 행사 알림** - 새로운 행사 등록 시
7. ✅ **신청 승인 알림** - 강의/행사 신청 승인 시
8. ✅ **신청 거절 알림** - 강의/행사 신청 거절 시
9. ✅ **기업 공지사항 알림** - 새로운 공지사항 등록 시

#### 사용자별 알림 설정 (v3.86.0)
- 전체 알림 ON/OFF 마스터 스위치
- 5가지 알림 타입별 개별 제어
- 알림 설정 페이지: `/notifications/settings`

### 🔧 5.2 FCM 프로젝트 설정

#### 1. Firebase Console에서 FCM 활성화
1. Firebase Console → 프로젝트 설정 → 클라우드 메시징
2. Cloud Messaging API (V1) 활성화
3. 서버 키 확인 (Legacy API - 더 이상 권장 안 함)

#### 2. 서비스 계정 키 다운로드
1. 프로젝트 설정 → 서비스 계정
2. "새 비공개 키 생성" 클릭
3. JSON 파일 다운로드
4. `/src/config/firebase-service-account.json` 저장

#### 3. OAuth 2.0 토큰 설정
```php
// src/helpers/FcmHelper.php
class FcmHelper {
    private static function getAccessToken() {
        $serviceAccountPath = __DIR__ . '/../config/firebase-service-account.json';
        // Google Auth Library를 사용한 OAuth 2.0 토큰 생성
    }
}
```

### 📁 5.3 서버 사이드 구현

**FcmHelper.php 주요 메서드:**
```php
// 개별 푸시 전송
FcmHelper::sendPush($fcmToken, $title, $body, $data);

// 대량 푸시 전송 (0.1초 지연)
```

**알림 트리거 예시 (CommentController.php):**
```php
// 1. 알림 설정 확인
if (NotificationSettings::isNotificationEnabled($recipientId, 'comments')) {

            $fcmTokens,
            '새 댓글이 달렸습니다',
            $commentText,
            ['type' => 'comment', 'post_id' => $postId]
        );
    }
}
```

## 6. 네이버 Maps API 설정

### 🗺️ 네이버 Maps API란?

네이버 클라우드 플랫폼(NCP)에서 제공하는 지도 서비스로, 한국 지역에 최적화된 지도 데이터를 제공합니다.

### 🎯 6.1 탑마케팅 활용 사례

#### 강의 상세 페이지 지도 표시
- 파일: `src/views/lectures/detail.php`
- 주소 자동 geocoding
- 커스텀 마커 및 정보창 표시
- 길찾기 링크 제공

### 🔧 6.2 네이버 클라우드 플랫폼 설정

#### 1. NCP 회원가입 및 프로젝트 생성
1. https://www.ncloud.com/ 접속
2. 회원가입 및 본인인증 완료

#### 2. Maps API 신청
1. Console > AI·Application Service > Maps 선택
2. Web Dynamic Map API 신청
3. 도메인 등록: `topmktx.com`, `www.topmktx.com`

#### 3. 클라이언트 ID 발급
- API 신청 승인 후 클라이언트 ID 발급
- 클라이언트 시크릿도 함께 발급됨

## 7. 카카오 주소 검색 API 설정

### 🔍 카카오 주소 검색 API란?

카카오에서 제공하는 주소 검색 및 좌표 변환 API로, 정확한 한국 주소 데이터를 제공합니다.

### 🎯 7.1 탑마케팅 활용 사례

#### 강의/행사 등록 시 주소 검색
- 주소 입력 자동완성
- 도로명 주소 및 지번 주소 변환
- 우편번호 자동 입력

### 🔧 7.2 카카오 Developers 설정

#### 1. 카카오 Developers 가입
1. https://developers.kakao.com 접속
2. 카카오 계정으로 로그인

#### 2. 애플리케이션 생성
1. "내 애플리케이션" → "애플리케이션 추가하기"
2. 앱 이름 입력 (예: 탑마케팅)
3. 사업자명 입력

#### 3. REST API 키 발급
1. 앱 설정 → 일반 → 앱 키
2. REST API 키 복사

#### 4. 플랫폼 등록
1. 앱 설정 → 플랫폼
2. Web 플랫폼 추가
3. 사이트 도메인 등록: `https://www.topmktx.com`

### 🔧 7.3 프로젝트 설정

**파일**: `src/config/config.php`

```php
// 카카오 주소 검색 API 설정
define('KAKAO_REST_API_KEY', '[REST_API_키]');  // ⚠️ 실제 키로 변경
```

### 📁 7.4 구현 예시

#### 주소 검색
```javascript
// Kakao 주소 검색 팝업
function searchAddress() {
    new daum.Postcode({
        oncomplete: function(data) {
            // 도로명 주소
            document.getElementById('address').value = data.roadAddress;
            // 우편번호
            document.getElementById('zipcode').value = data.zonecode;
        }
    }).open();
}
```

#### 좌표 변환
```javascript
// 주소 → 좌표 변환
fetch(`https://dapi.kakao.com/v2/local/search/address.json?query=${address}`, {
    headers: {
        'Authorization': `KakaoAK ${KAKAO_REST_API_KEY}`
    }
})
.then(response => response.json())
.then(data => {
    const { x, y } = data.documents[0];
    console.log(`좌표: ${x}, ${y}`);
});
```

## 10. 문제 해결

### 🚨 10.1 SMS 관련 오류

| 오류 코드 | 원인 | 해결 방법 |
|----------|------|----------|
| -101 | API 키 오류 | API 키 재확인 |
| -102 | 사용자 ID 오류 | 사용자 ID 재확인 |
| -103 | 발신번호 미등록 | 발신번호 등록/승인 |
| -201 | 잔액 부족 | SMS 충전 |

### 🔐 10.2 reCAPTCHA 관련 오류

1. **timeout-or-duplicate**: 토큰 재사용 또는 만료
   - 새 토큰 생성 후 재시도

2. **missing-input-secret**: 비밀 키 누락
   - AuthController.php의 secretKey 확인

3. **invalid-input-secret**: 잘못된 비밀 키
   - reCAPTCHA 콘솔에서 키 재확인

4. **missing-input-response**: 토큰 누락
   - 클라이언트에서 토큰 생성 확인

### 🔥 10.3 Firebase 관련 오류

#### 연결 실패
```javascript
// Firebase 연결 상태 확인
firebase.database().ref('.info/connected').on('value', (snapshot) => {
    if (snapshot.val() === true) {
        console.log('✅ Firebase 연결 활성');
    } else {
        console.log('❌ Firebase 연결 끊김');
    }
});
```

#### 권한 오류
- Firebase Console → Realtime Database → 규칙
- 보안 규칙 재확인
- 인증 토큰 확인

### 📱 10.4 FCM 관련 오류

#### 푸시 전송 실패
- FCM 토큰 만료 확인
- OAuth 2.0 토큰 갱신
- Firebase Console → Cloud Messaging 활성화 확인

#### 앱에서 토큰 등록 실패
- JavaScript 함수 `registerFCMTokenFromApp` 존재 확인
- 로그인 상태 확인 (로그인 필수)
- 브라우저 콘솔 오류 확인

### 🗺️ 10.5 네이버 Maps 관련 오류

#### 인증 실패 (Authentication Failed)
- 클라이언트 ID 재확인
- 도메인 등록 상태 확인 (NCP Console)
- CSP 정책에 네이버 도메인 추가 확인

#### Geocoding 실패
- 주소 형식 확인 (한글 주소)
- API 사용량 확인
- 네트워크 방화벽 설정 확인

### 📞 10.6 고객지원 연락처

- **알리고 고객센터**: 1588-7979 (평일 9:00~18:00)
- **Google reCAPTCHA 지원**: https://support.google.com/recaptcha
- **Firebase 지원**: https://firebase.google.com/support
- **네이버 클라우드 고객센터**: 1544-1876
- **카카오 Developers 지원**: https://developers.kakao.com/support
