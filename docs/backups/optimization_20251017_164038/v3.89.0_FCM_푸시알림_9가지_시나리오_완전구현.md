## 개요

### 🎯 프로젝트 목적

탑마케팅 플랫폼에서 사용자에게 중요한 이벤트(댓글, 좋아요, 신청 결과 등)를 **실시간 푸시 알림**으로 전달하여 사용자 참여도와 만족도를 극대화합니다.

### ✅ 주요 성과

- **9가지 푸시 알림 시나리오** 100% 구현 완료
- **치명적 버그 3건** 발견 및 수정 (사용자 알림 설정 무시 문제)
- **사용자 알림 설정 시스템** 완벽 통합 (v3.86.0)
- **보안, 에러 처리, 로깅** 완벽 구현
- **프로덕션 배포 준비 완료**

### 📊 통계

- **수정된 파일**: 9개 (컨트롤러 7개, 라우트 1개, QA 문서 1개)

## 기술 아키텍처

### 📐 시스템 구조

```
┌──────────────────────────────────────────────────────────────┐
│                   FCM 푸시 알림 시스템 구조                    │
└──────────────────────────────────────────────────────────────┘

1. 사용자 액션 (댓글 작성, 좋아요, 신청 등)
   ↓
2. 컨트롤러 (CommentController, LikeController 등)
   ↓
3. NotificationSettings::isNotificationEnabled() 확인
   ↓ (활성화된 경우만)
4. FcmTokenModel::getTokensByUserId() - 토큰 조회
   ↓
5. FcmHelper::sendPush() - FCM V1 API 호출
   ↓
6. Firebase Cloud Messaging
   ↓
7. 사용자 디바이스 (Android/iOS 앱)
```

### 🔀 두 가지 전송 패턴

#### 패턴 1: 개별 전송 (Individual Sending)

**사용처**: 댓글, 대댓글, 좋아요, 채팅, 신청 승인/거절

**특징**:
- `FcmHelper::sendPush($token, $title, $body, $data)` 사용
- **알림 설정을 자동으로 확인하지 않음** ⚠️
- 개발자가 수동으로 `isNotificationEnabled()` 호출 필수

**코드 패턴**:
```php
// ✅ 올바른 사용법 (알림 설정 확인)
$notificationSettings = new NotificationSettings();
if ($notificationSettings->isNotificationEnabled($userId, 'comments')) {
    $tokens = $fcmTokenModel->getTokensByUserId($userId);
    foreach ($tokens as $token) {
        FcmHelper::sendPush($token['fcm_token'], $title, $body, $data);
    }
}

// ❌ 잘못된 사용법 (알림 설정 무시) - v3.89.0 이전 버그
$tokens = $fcmTokenModel->getTokensByUserId($userId);
foreach ($tokens as $token) {
    FcmHelper::sendPush($token['fcm_token'], $title, $body, $data);
}
```

---

#### 패턴 2: 브로드캐스트 전송 (Broadcast Sending)

**사용처**: 신규 강의, 신규 행사, 기업 공지사항

**특징**:
- `FcmHelper::sendByNotificationType($type, $title, $body, $data)` 사용
- **알림 설정을 자동으로 확인** ✅
- 개발자가 수동 확인 불필요

**코드 패턴**:
```php
// ✅ 자동으로 알림 설정 확인
$result = FcmHelper::sendByNotificationType(
    'lectures_events',
    '새 강의 알림',
    '새로운 강의가 등록되었습니다.',
    ['type' => 'lecture', 'lecture_id' => $lectureId]
);

// 내부적으로 NotificationSettings::getEnabledUserIds() 호출
```

### 🛡️ 보안 및 검증

#### 1️⃣ 인증 (Authentication)

- **모든 알림 트리거**: AuthMiddleware 필수
- **로그인하지 않은 사용자**: 알림 전송 불가
- **세션 기반 인증**: `$_SESSION['user_id']` 확인

#### 2️⃣ CSRF 보호

- **ChatController API**: CSRF 토큰 검증 필수
- **토큰 불일치 시**: 403 Forbidden 응답
- **토큰 재생 공격 방지**: 세션 기반 토큰 관리

#### 3️⃣ 자기 알림 제외 (Self-Notification Prevention)

```php
// 댓글 예시
if ($post['user_id'] != $currentUserId) {
    // 게시글 작성자에게만 알림
}

// 좋아요 예시
if ($post && $post['user_id'] != $currentUserId) {
    // 좋아요를 누른 사람 제외
}

// 채팅 예시
if ($recipientId != $currentUserId) {
    // 보낸 사람 제외
}
```

#### 4️⃣ 알림 설정 확인 (v3.89.0)

```php
// 개별 전송 (수동 확인 필수)
if (!$notificationSettings->isNotificationEnabled($userId, 'comments')) {
    WebLogger::info('댓글 알림 스킵 (알림 설정 OFF)', [...]);
    return;
}

// 브로드캐스트 전송 (자동 확인)
$enabledUserIds = $notificationSettings->getEnabledUserIds('lectures_events');
// 알림 활성화한 사용자에게만 전송
```

#### 문제 1: 알림이 전송되지 않음

**원인**:
1. Firebase 서비스 계정 JSON 파일 경로 오류
2. FCM 토큰이 만료됨
3. 사용자가 알림 설정 OFF (v3.89.0)

**해결**:
```bash
# 1. Firebase 서비스 계정 확인
ls -la /path/to/topmkt-832f2-firebase-adminsdk-*.json

# 2. FCM 토큰 확인
mysql -u root -p topmkt_db -e "SELECT * FROM fcm_tokens WHERE user_id = 1 AND is_active = 1;"

# 3. 알림 설정 확인 (v3.89.0)
mysql -u root -p topmkt_db -e "SELECT * FROM notification_settings WHERE user_id = 1;"

# 4. 로그 확인
grep "FCM 알림 전송 실패" /var/www/html/topmkt/logs/web_$(date +%Y%m%d).log
```

$recipientIds = array_unique($recipientIds);  // 중복 제거 확인
