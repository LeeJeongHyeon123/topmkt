# v3.72.0 - 신청 마감일 날짜/시간 Input 분리 완전 개선

## 📋 개요

**버전**: v3.72.0
**날짜**: 2025-10-10
**작업자**: Claude (Anthropic)
**작업 모드**: Ultra Think 모드

## 🎯 문제 정의

### 사용자 피드백
1. **UI 불일치**: 신청 마감일만 Flatpickr로 날짜+시간이 하나의 input에 표시
2. **일관성 부족**: 시작일/종료일은 날짜와 시간이 분리된 input인데 신청 마감일만 다름
3. **사용자 요청**: "시작일, 종료일과 동일하게 날짜/시간을 분리해야 일관성이 유지됨"

### 기술적 문제
- Flatpickr 사용으로 인한 복잡한 JavaScript 코드 (229줄)
- 네이티브 input과 다른 UI/UX
- 불필요한 라이브러리 의존성

## 🔧 해결 과정

### 1단계: v3.68.2 - Flatpickr UI 개선 시도
**문제**: 5가지 UI 문제 발견
- 시간/오전오후 글씨 정렬 불일치
- 월 선택 박스 부자연스러움
- 테두리 컬러 이상함
- 년도 선택 불가
- 오전오후 글씨 짤림 ("오"만 표시)

**해결**:
- 년도 입력 활성화 (`removeAttribute('disabled')`)
- AM/PM 최소 너비 70px로 확장
- 모든 요소 38px 높이 통일
- 월 드롭다운 스타일 개선
- 테두리 색상 보라색으로 통일

### 2단계: v3.68.3~v3.68.5 - 색상 통일 문제
**문제**: 시작일/종료일 네이티브 input과 Flatpickr 색상 불일치

**시행착오**:
- v3.68.3: Flatpickr를 보라색(#667eea)으로 통일 시도
- v3.68.4: 모든 input을 보라색으로 강제 변경 (잘못된 방향)
- v3.68.5: 사용자 정정 - 파란색(#007bff)으로 통일이 맞음

**교훈**: 네이티브 브라우저 input의 기본 색상은 파란색

### 3단계: v3.69.0 - Flatpickr UI 완전 재디자인
**문제**: 색상이 너무 진하고 부자연스러움

**해결**:
- 진한 파란색 → 연한 하늘색 (#e0f2fe, #7dd3fc)
- 3px 테두리 → 1px 테두리
- 그라디언트 배경 → 흰색 배경
- 18px/굵게 폰트 → 14px/보통 폰트
- 모든 시각 요소 경량화

### 4단계: v3.70.0~v3.70.1 - "T" 구분자 제거
**문제**: 날짜와 시간 사이에 "T" 표시 ("2025-10-17T12:00")

**원인**:
- `type="datetime-local"` → ISO 8601 형식 강제
- onChange 콜백에서 T 포함 형식으로 강제 변환

**해결**:
- v3.70.0: input type을 "text"로 변경, PHP 출력 형식 수정
- v3.70.1: onChange 콜백에서 T 제거 (공백 구분으로 변경)

### 5단계: v3.71.0 - 시간 입력 UI 개선
**문제**:
- 시간 입력 박스 높이 너무 좁아 답답함 (32px)
- 입력 가능한 UI처럼 보이지 않음
- 오전/오후 버튼 글씨 세로 정렬 불일치

**해결**:
- 시간 입력 높이: 32px → 40px
- 오전/오후 버튼 높이: 32px → 40px
- flexbox로 완벽한 세로 정렬 (align-items: center)
- line-height: 40px 추가

### 6단계: v3.72.0 - 완전한 날짜/시간 분리 (최종 완성)
**사용자 요청**: "시작일/종료일처럼 분리해야 일관성 유지"

**HTML 구조 변경**:
```html
<!-- Before: Flatpickr 단일 input -->
<input type="text" id="registration_deadline" ...>

<!-- After: 네이티브 input 분리 -->
<input type="date" id="registration_deadline_date" ...>
<input type="time" id="registration_deadline_time" ...>
<input type="hidden" id="registration_deadline" ...> <!-- 백엔드 전송용 -->
```

**JavaScript 변경**:
- Flatpickr 61줄 완전 제거
- 네이티브 input 클릭 이벤트 추가 (18줄)
- 폼 제출 시 날짜+시간 자동 합치기 (8줄)

**CSS 변경**:
- Flatpickr 168줄 완전 제거
- 네이티브 input 포커스 스타일만 유지 (10줄)
