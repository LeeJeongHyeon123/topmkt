## 🚨 해결된 주요 문제들

### 1. 공지사항 #16: Quill 에디터 이미지 업로드 실패
**문제**: Quill 에디터의 이미지 버튼 클릭 시 파일 업로드가 이루어지지 않고 빈 `<img>` 태그만 생성  
**근본 원인**: Quill 에디터에 커스텀 imageHandler가 없어 기본 동작(URL 입력 프롬프트)만 실행됨  

**해결책**:
- `quillImageHandler()` 함수 구현으로 파일 선택 다이얼로그 제공
- `uploadImageToQuill()` 함수로 MediaController와 완전 연동
- 실시간 로딩 피드백 및 포괄적 오류 처리
- 30MB 파일 크기 제한 및 이미지 형식 검증

### 2. 공지사항 #17: 중복 업로드 문제
**문제**: Quill 에디터로 업로드한 이미지가 본문과 첨부 이미지 영역 양쪽에 동시 표시  
**근본 원인**: 같은 디렉토리에 저장되어 Notice 모델이 모든 이미지를 첨부 이미지로 인식  

**해결책**:
- 업로드 타입 분리: Quill 업로드 → `/uploads/notices-content/`, 일반 첨부 → `/uploads/notices/`
- MediaController에 `is_quill_upload` 파라미터 추가
- Notice 모델에서 Quill 업로드 이미지 제외 로직 구현

### 3. 공지사항 #18: 잘못된 이미지 표시 문제
**문제**: 새 공지사항에 B 이미지를 업로드했는데 이전 공지사항의 A 이미지가 표시됨  
**근본 원인**: Notice 모델의 시간 범위 검색이 "-5분 ~ +30분"으로 너무 넓어 다른 공지사항 이미지까지 포함  

**해결책**:
- 시간 범위 대폭 축소: "-5분/+30분" → "-1분/+1분"
- 정밀한 타임스탬프 기반 이미지 매칭
- 공지사항 간 이미지 충돌 완전 방지

### 1. Quill 에디터 완전 통합
**파일**: `src/views/notices/write.php`, `src/views/notices/edit.php`

```javascript
// 커스텀 이미지 핸들러
function quillImageHandler() {
    const input = document.createElement('input');
    input.setAttribute('type', 'file');
    input.setAttribute('accept', 'image/*');
    // ... 파일 검증 및 업로드 로직
}

// Quill 설정
quill = new Quill('#editor-container', {
    modules: {
        toolbar: {
            container: toolbarOptions,
            handlers: {
                image: quillImageHandler  // 커스텀 핸들러 연결
            }
        }
    }
});
```

### 2. MediaController 업로드 타입 분리
**파일**: `src/controllers/MediaController.php`

```php
private function determineUploadType() {
    $isQuillUpload = $_POST['is_quill_upload'] ?? false;
    
    // Quill 에디터 업로드는 별도 디렉토리
    if ($isQuillUpload) {
        if (strpos($referer, '/notices/') !== false) {
            return 'notices-content';  // 분리된 디렉토리
        }
    }
    // ... 기존 로직
}
```
