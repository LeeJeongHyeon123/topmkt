## 시스템 개요

### 🎯 현재 상태

탑마케팅 관리자 시스템은 **서비스 초기 단계**에 맞춰 **핵심 기능에만 집중**하는 간소화된 구조입니다.

**설계 철학** (v3.76.0, v3.11.5):
- "서비스 초기 단계에서는 불필요한 대시보드보다 **기업 인증 처리가 우선순위**"
- 404 에러 발생 메뉴 완전 제거 (사용자 경험 개선)
- 관리자 메뉴 9개 → **3개 핵심 메뉴**로 최적화 (56% 축소)

### ✅ 주요 특징

- **초간단 구조**: 3개 메뉴만 제공 (회원 관리 + 기업 인증)
- **권한 기반 접근**: ROLE_ADMIN 권한자만 접근 가능
- **자동 리다이렉트**: /admin 접속 시 /admin/corporate/pending으로 자동 이동
- **역할 분리**: 시스템 관리자 vs 기업 관리자 명확한 구분
- **독립적 UI**: 사용자 페이지와 완전 분리된 관리자 전용 인터페이스

## 접근 방법

### 🔐 관리자 시스템 접속

```
URL: https://www.topmktx.com/admin
권한: ROLE_ADMIN (시스템 관리자만)
자동 리다이렉트: /admin/corporate/pending (기업 인증 대기 페이지)
```

### 🔒 권한 확인 시스템

```php
// AdminController에서 모든 요청마다 권한 확인
private function checkAdminAccess() {
    if (!AuthMiddleware::isLoggedIn()) {
        header('Location: /auth/login');
        exit;
    }

    $userRole = AuthMiddleware::getCurrentUserRole();
    if ($userRole !== 'ROLE_ADMIN') {
        header('Location: /errors/403');
        exit;
    }
}
```

## 주요 기능

### 📋 현재 관리자 메뉴 구조 (3개)

```
관리자 시스템 (/admin)
│
├── 👥 회원 관리
│   └── 회원 목록 (/admin/users)
│       - 전체 사용자 조회
│       - 권한 변경 (일반/기업/관리자)
│       - 계정 상태 관리
│
└── 🏢 기업회원
    ├── ⏱️ 인증 대기 (/admin/corporate/pending)
    │   - 기업 인증 신청 검토
    │   - 승인/거절 처리
    │   - SMS 알림 자동 발송
    │
    └── 📋 기업회원 목록 (/admin/corporate/list)
        - 승인된 기업회원 관리
        - 기업 정보 확인
```

### 1️⃣ 회원 목록 (/admin/users)

**기능**:
- 전체 사용자 목록 조회
- 사용자 검색 및 필터링
- 권한 변경: ROLE_USER ↔ ROLE_CORP ↔ ROLE_ADMIN
- 계정 상태 관리

**주요 정보**:
- 닉네임, 이메일, 전화번호
- 현재 권한 (일반/기업/관리자)
- 가입일, 마지막 로그인
- 게시글 수, 댓글 수

### 2️⃣ 기업 인증 대기 (/admin/corporate/pending)

**기능**:
- 기업 인증 신청 목록 조회
- 사업자등록증 확인
- 승인/거절 처리
- 관리자 메모 작성
- SMS 알림 자동 발송

**승인 프로세스**:
1. 신청 내용 검토 (회사명, 사업자번호, 서류)
2. 승인 또는 거절 선택
3. 관리자 메모 작성 (선택)
4. 처리 완료
5. **자동 SMS 발송** (승인/거절 알림)
6. **권한 자동 변경** (승인 시 ROLE_USER → ROLE_CORP)

**코드 예시**:
```php
// 기업인증 승인 시
public function approveCorporate($corporateId) {
    $corporate = Corporate::find($corporateId);
    $corporate->status = 'approved';
    $corporate->approved_by = AuthMiddleware::getCurrentUserId();
    $corporate->save();

    // 사용자 권한 업데이트
    User::updateRole($corporate->user_id, 'ROLE_CORP');

    // 승인 SMS 발송
    $this->sendCorporateApprovalSms($corporate);

    // 활동 로깅
    $this->logAdminActivity('CORPORATE_APPROVED', [
        'corporate_id' => $corporateId,
        'company_name' => $corporate->company_name
    ]);
}
```

### 3️⃣ 기업회원 목록 (/admin/corporate/list)

**기능**:
- 승인된 기업회원 전체 목록
- 기업 정보 상세 확인
- 기업별 활동 통계 (등록한 강의/행사 수)

## 역할 기반 관리 체계

### 🏛️ 시스템 관리자 (ROLE_ADMIN)

**관리 범위**: 플랫폼 전체 운영

**접근 페이지**:
- `/admin/users` - 회원 목록
- `/admin/corporate/pending` - 기업 인증 대기
- `/admin/corporate/list` - 기업회원 목록

**핵심 권한**:
- 회원 권한 변경
- 기업 인증 승인/거절
- 시스템 전체 모니터링

### 🏢 기업 관리자 (ROLE_CORP)

**관리 범위**: 자신의 콘텐츠만

**접근 페이지**:
- `/registrations` - 강의/행사 신청 관리 (RegistrationDashboardController)

**핵심 권한**:
- 자신이 등록한 강의/행사 관리
- 신청자 승인/거절
- 신청 통계 확인

**참고**: 기업 관리자는 `/admin` 페이지 접근 불가 (403 Forbidden)

### 📝 AdminController 주요 메서드

```php
class AdminController extends BaseController {

    public function __construct() {
        parent::__construct();
        $this->checkAdminAccess(); // 모든 요청마다 권한 확인
    }

    // 대시보드 (자동 리다이렉트)
    public function dashboard() {
        header('Location: /admin/corporate/pending');
        exit;
    }

    // 회원 목록
    public function userList()

    // 기업 인증 목록
    public function corporateList()

    // 기업 인증 승인
    public function approveCorporate($corporateId)

    // 기업 인증 거절
    public function rejectCorporate($corporateId)
}
```

### 🔐 보안 조치

**활동 로깅**:
```php
// 모든 관리자 활동 자동 기록
private function logAdminActivity($action, $details = null) {
    $logData = [
        'admin_id' => AuthMiddleware::getCurrentUserId(),
        'action' => $action,
        'details' => $details,
        'ip_address' => $_SERVER['REMOTE_ADDR'],
        'user_agent' => $_SERVER['HTTP_USER_AGENT'],
        'timestamp' => date('Y-m-d H:i:s')
    ];

    WebLogger::info("관리자 활동", $logData);
}
```

**세션 보안**:
- JWT 기반 인증 (30일 장기 로그인)
- 권한 확인: ROLE_ADMIN 필수
- 403 에러: 권한 없는 사용자 차단
