## 버튼 컴포넌트 (Button.php)

### 🎯 사용 목적

모든 버튼을 **일관된 스타일과 동작**으로 통합 관리합니다.

### 📦 불러오기

```php
<?php require_once SRC_PATH . '/components/ui/Button.php'; ?>
```

---

### 기본 사용법

#### 1. 주요 액션 버튼 (저장, 등록, 확인)

```php
<?= renderButton('저장', 'primary') ?>
<?= renderButton('등록', 'primary', 'lg') ?>
<?= renderButton('확인', 'primary', 'md', ['buttonType' => 'submit']) ?>
```

**결과**:
- 파란색 그라디언트 버튼
- 크기: md (기본), lg (큰 버튼)
- type="submit" (폼 제출용)

#### 2. 보조 액션 버튼 (취소, 목록)

```php
<?= renderButton('취소', 'secondary') ?>
<?= renderButton('목록', 'secondary', 'md', ['href' => '/lectures']) ?>
```

**결과**:
- 회색 버튼
- 링크 버튼 (href 지정 시 `<a>` 태그로 렌더링)

#### 3. 위험 액션 버튼 (삭제)

```php
<?= renderButton('삭제', 'danger', 'md', [
    'icon' => 'fas fa-trash',
    'onclick' => 'confirmDelete()'
]) ?>
```

**결과**:
- 빨간색 버튼
- 아이콘 포함
- 클릭 이벤트 연결

#### 4. 성공/경고/정보 버튼

```php
<?= renderButton('승인', 'success') ?>
<?= renderButton('경고', 'warning') ?>
<?= renderButton('상세보기', 'info') ?>
```

#### 5. 아웃라인 버튼

```php
<?= renderButton('자세히', 'outline') ?>
```

**결과**:
- 투명 배경 + 테두리만

---

### 📏 버튼 크기

| 크기 | 높이 | 용도 | 예시 |
|-----|------|------|------|
| `sm` | 36px | 작은 버튼 (테이블 액션) | `renderButton('수정', 'primary', 'sm')` |
| `md` | 44px | 기본 버튼 (대부분) | `renderButton('저장', 'primary', 'md')` |
| `lg` | 52px | 큰 버튼 (CTA) | `renderButton('시작하기', 'primary', 'lg')` |

> **접근성 보장**: 모든 크기는 최소 터치 타겟 44px 이상 (WCAG 2.1 AAA)

---

### 🎨 버튼 타입 및 색상

| 타입 | 색상 | 용도 |
|------|------|------|
| `primary` | 파란 그라디언트 (#1e88e5) | 주요 액션 |
| `secondary` | 회색 (#f5f5f5) | 보조 액션 |
| `danger` | 빨강 (#e53935) | 삭제/위험 |
| `success` | 초록 그라디언트 (#48bb78) | 성공/승인 |
| `warning` | 주황 (#F59E0B) | 경고/주의 |
| `info` | 파랑 (#3b82f6) | 정보/상세 |
| `outline` | 투명 + 테두리 | 부드러운 액션 |

### 🔧 고급 옵션

#### 전체 너비 버튼

```php
<?= renderButton('로그인', 'primary', 'lg', ['fullWidth' => true]) ?>
```

#### 아이콘 위치 지정

```php
// 왼쪽 아이콘 (기본)
<?= renderButton('저장', 'primary', 'md', [
    'icon' => 'fas fa-save',
    'iconPosition' => 'left'
]) ?>

// 오른쪽 아이콘
<?= renderButton('다음', 'primary', 'md', [
    'icon' => 'fas fa-arrow-right',
    'iconPosition' => 'right'
]) ?>
```

#### 비활성화 버튼

```php
<?= renderButton('제출 중...', 'primary', 'md', ['disabled' => true]) ?>
```

#### 접근성 레이블

```php
// 아이콘 전용 버튼에 필수!
<?= renderButton('', 'danger', 'sm', [
    'icon' => 'fas fa-trash',
    'ariaLabel' => '삭제'
]) ?>
```

#### 추가 HTML 속성

```php
<?= renderButton('제출', 'primary', 'md', [
    'attributes' => [
        'data-action' => 'submit-form',
        'data-confirm' => 'true'
    ]
]) ?>
```

### 📚 실전 예제

#### 예제 1: 폼 제출 버튼

```php
<form method="POST" action="/lectures/create">
    <!-- 폼 필드들 -->
    
    <div style="margin-top: 20px;">
        <?= renderButtonGroup([
            ['저장', 'primary', 'md', ['buttonType' => 'submit']],

    </div>

```

#### 예제 2: 테이블 액션 버튼

```php
<td>
    <?= renderButton('', 'info', 'sm', [
        'icon' => 'fas fa-eye',
        'ariaLabel' => '상세보기',
        'href' => "/users/{$user['id']}"
    ]) ?>
    
    <?= renderButton('', 'primary', 'sm', [
        'icon' => 'fas fa-edit',
        'ariaLabel' => '수정',
        'onclick' => "editUser({$user['id']})"
    ]) ?>
    
    <?= renderButton('', 'danger', 'sm', [
        'icon' => 'fas fa-trash',
        'ariaLabel' => '삭제',
        'onclick' => "deleteUser({$user['id']})"
    ]) ?>
</td>
```

#### 예제 3: 모달 푸터 버튼

```php
<div class="modal-footer">
    <?= renderButtonGroup([
        ['확인', 'primary', 'md', ['onclick' => 'submitModal()']],
        ['취소', 'secondary', 'md', ['onclick' => 'closeModal()']]
    ], ['align' => 'right']) ?>
</div>
```

## 컴포넌트 사용 규칙

### ✅ 반드시 지켜야 할 규칙

1. **새 페이지 작성 시**: 파일 상단에 사용 가능한 컴포넌트 목록 주석 추가
2. **버튼 코딩 시**: 항상 `renderButton()` 사용, 직접 HTML 작성 금지
3. **스타일 수정 시**: main.css 수정, 페이지별 인라인 CSS 금지

### 📝 파일 상단 주석 템플릿

```php
<?php
/**
 * 📦 사용 가능한 컴포넌트 목록
 * 
 * UI 컴포넌트:
 * - Button.php           : renderButton($text, $type, $size, $options)
 * - Modal.php            : renderModal($id, $title, $content)
 * - Alert.php            : showAlert($message, $type)
 * 
 * 📖 자세한 사용법: /docs/23.컴포넌트_사용_가이드.md
 */

require_once SRC_PATH . '/components/ui/Button.php';

// 여기서부터 실제 코드 시작...
?>
```

## 문제 해결

### Q1. 컴포넌트 파일을 찾을 수 없어요

```
Fatal error: require_once(): Failed opening required '/var/www/html/topmkt/src/components/ui/Button.php'
```

**해결**: SRC_PATH 상수 확인

```php
// 파일 상단에 추가
define('SRC_PATH', __DIR__ . '/../src');
```

### Q2. 버튼 스타일이 적용되지 않아요

**원인**: main.css가 로드되지 않음

**해결**: header.php에 CSS 포함 확인

```html
<link rel="stylesheet" href="/assets/css/main.css">
```

### Q3. 특정 페이지에서만 다른 스타일이 필요해요

**해결**: `class` 옵션 사용

```php
<?= renderButton('특별 버튼', 'primary', 'md', ['class' => 'my-custom-class']) ?>
```

### Q4. Claude Code로 개발 시 컴포넌트 사용법

**해결**: 파일 상단 주석 및 이 가이드 문서 참고

1. 작업 시작 전 이 문서 확인
2. 파일 상단 컴포넌트 주석 확인
3. `renderButton()` 함수 사용
