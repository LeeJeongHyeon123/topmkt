## 버튼 컴포넌트 (Button.php)

### 🎯 사용 목적

모든 버튼을 **일관된 스타일과 동작**으로 통합 관리합니다.

### 📦 불러오기

```php
<?php require_once SRC_PATH . '/components/ui/Button.php'; ?>
```

---

### 기본 사용법

#### 1. 주요 액션 버튼 (저장, 등록, 확인)

```php
<?= renderButton('저장', 'primary') ?>
<?= renderButton('등록', 'primary', 'lg') ?>
<?= renderButton('확인', 'primary', 'md', ['buttonType' => 'submit']) ?>
```

**결과**:
- 파란색 그라디언트 버튼
- 크기: md (기본), lg (큰 버튼)
- type="submit" (폼 제출용)

#### 2. 보조 액션 버튼 (취소, 목록)

```php
<?= renderButton('취소', 'secondary') ?>
<?= renderButton('목록', 'secondary', 'md', ['href' => '/lectures']) ?>
```

**결과**:
- 회색 버튼
- 링크 버튼 (href 지정 시 `<a>` 태그로 렌더링)

#### 3. 위험 액션 버튼 (삭제)

```php
<?= renderButton('삭제', 'danger', 'md', [
    'icon' => 'fas fa-trash',
    'onclick' => 'confirmDelete()'
]) ?>
```

**결과**:
- 빨간색 버튼
- 아이콘 포함
- 클릭 이벤트 연결

#### 4. 성공/경고/정보 버튼

```php
<?= renderButton('승인', 'success') ?>
<?= renderButton('경고', 'warning') ?>
<?= renderButton('상세보기', 'info') ?>
```

#### 5. 아웃라인 버튼

```php
<?= renderButton('자세히', 'outline') ?>
```

**결과**:
- 투명 배경 + 테두리만

---

### 📏 버튼 크기

| 크기 | 높이 | 용도 | 예시 |
|-----|------|------|------|
| `sm` | 36px | 작은 버튼 (테이블 액션) | `renderButton('수정', 'primary', 'sm')` |
| `md` | 44px | 기본 버튼 (대부분) | `renderButton('저장', 'primary', 'md')` |
| `lg` | 52px | 큰 버튼 (CTA) | `renderButton('시작하기', 'primary', 'lg')` |

> **접근성 보장**: 모든 크기는 최소 터치 타겟 44px 이상 (WCAG 2.1 AAA)

---

### 🎨 버튼 타입 및 색상

| 타입 | 색상 | 용도 |
|------|------|------|
| `primary` | 파란 그라디언트 (#1e88e5) | 주요 액션 |
| `secondary` | 회색 (#f5f5f5) | 보조 액션 |
| `danger` | 빨강 (#e53935) | 삭제/위험 |
| `success` | 초록 그라디언트 (#48bb78) | 성공/승인 |
| `warning` | 주황 (#F59E0B) | 경고/주의 |
| `info` | 파랑 (#3b82f6) | 정보/상세 |
| `outline` | 투명 + 테두리 | 부드러운 액션 |

## 모달 컴포넌트 (Modal.php)

### 🎯 사용 목적

모든 모달(팝업)을 **일관된 스타일과 동작**으로 통합 관리합니다.

### 📦 불러오기

```php
<?php require_once SRC_PATH . '/components/ui/Modal.php'; ?>
<script src="/assets/js/modal.js"></script>
```

---

### 기본 사용법

#### 1. 기본 모달 (정보 표시용)

```php
<?= renderModal('info-modal', '공지사항', '<p>시스템 점검 안내입니다.</p>') ?>
```

**결과**:
- 중간 크기 (600px) 모달
- 닫기 버튼 (X) 포함
- ESC 키 및 배경 클릭으로 닫기 가능

#### 2. 푸터 버튼이 있는 모달 (확인/취소)

```php
<?= renderModal('confirm-modal', '삭제 확인', '<p>정말 삭제하시겠습니까?</p>', [
    'footerButtons' => [
        ['text' => '삭제', 'type' => 'danger', 'onclick' => 'deleteItem()'],
        ['text' => '취소', 'type' => 'secondary', 'onclick' => 'closeModal("confirm-modal")']
    ]
]) ?>
```

**결과**:
- 푸터에 삭제/취소 버튼 표시
- 버튼은 Button.php 컴포넌트 자동 사용

#### 3. 큰 모달 (폼 입력용)

```php
<?= renderModal('edit-modal', '회원 정보 수정', $formHtml, [
    'size' => 'lg',
    'footerButtons' => [
        ['text' => '저장', 'type' => 'primary', 'onclick' => 'saveUser()'],
        ['text' => '취소', 'type' => 'secondary', 'onclick' => 'closeModal("edit-modal")']
    ]
]) ?>
```

**결과**:
- 큰 크기 (800px) 모달
- 복잡한 폼 입력에 적합

#### 4. 간단한 확인 모달 (헬퍼 함수)

```php
<?= renderConfirmModal('delete-confirm', '삭제 확인', '정말 삭제하시겠습니까?', 'deleteUser(123)') ?>
```

**결과**:
- 작은 크기 (400px) 확인 모달
- 확인/취소 버튼 자동 생성
- 확인 버튼은 빨간색 (danger)

---

### 📏 모달 크기

| 크기 | 너비 | 용도 | 예시 |
|-----|------|------|------|
| `sm` | 400px | 간단한 확인 | `renderModal('id', '제목', '내용', ['size' => 'sm'])` |
| `md` | 600px | 기본 모달 (기본값) | `renderModal('id', '제목', '내용')` |
| `lg` | 800px | 폼 입력 | `renderModal('id', '제목', $form, ['size' => 'lg'])` |
| `xl` | 1200px | 복잡한 콘텐츠 | `renderModal('id', '제목', $content, ['size' => 'xl'])` |

### 🎮 JavaScript 함수

모달을 제어하는 JavaScript 함수들 (`modal.js`에 포함):

#### openModal(modalId)
```javascript
// 모달 열기
openModal('user-detail-modal');
```

#### closeModal(modalId)
```javascript
// 모달 닫기
closeModal('user-detail-modal');
```

#### closeAllModals()
```javascript
// 모든 열린 모달 닫기
closeAllModals();
```

#### 동적 모달 생성

```javascript
// JavaScript로 즉시 모달 생성 및 표시
createModal('dynamic-modal', '동적 제목', '<p>동적 내용</p>', [
    {text: '확인', type: 'primary', onclick: 'closeModal("dynamic-modal")'}
]);
openModal('dynamic-modal');
```

#### 간편 함수

```javascript
// 확인 다이얼로그
showConfirmModal('정말 삭제하시겠습니까?', function() {
    deleteItem();
});

// 알림 다이얼로그
showAlertModal('저장되었습니다!');
```

## 컴포넌트 사용 규칙

### ✅ 반드시 지켜야 할 규칙

1. **새 페이지 작성 시**: 파일 상단에 사용 가능한 컴포넌트 목록 주석 추가
2. **버튼 코딩 시**: 항상 `renderButton()` 사용, 직접 HTML 작성 금지
3. **모달 코딩 시**: 항상 `renderModal()` 또는 `renderConfirmModal()` 사용, 직접 HTML 작성 금지
4. **스타일 수정 시**: main.css 수정, 페이지별 인라인 CSS 금지

### 📝 파일 상단 주석 템플릿

```php
<?php
/**
 * 📦 사용 가능한 컴포넌트 목록

 * - Modal.php            : renderModal($id, $title, $bodyContent, $options)
 * - Alert.php            : showAlert($message, $type) (예정)
 *

 */

```

## Claude Code 개발 시 주의사항

### 🤖 Claude Code로 바이브 코딩 시

**중요**: 이 프로젝트는 IDE 없이 Claude Code CLI로만 개발됩니다.

**컴포넌트 사용 방지 대책**:

1. **작업 시작 전 필수 체크**
   ```bash
   # 이 가이드 문서 확인
   cat /var/www/html/topmkt/docs/23.컴포넌트_사용_가이드.md
   ```

2. **파일 상단 주석 확인**
   - 모든 뷰 파일 상단에 사용 가능한 컴포넌트 목록 주석 있음
   - Claude가 파일 읽을 때마다 확인하도록 설계됨

3. **작업 완료 후 자동 검증**
   ```bash
   # 컴포넌트 미사용 감지 스크립트 실행 (수동)
   ./scripts/check_component_violations.sh

   # Git 커밋 시 자동 검증 (Pre-commit Hook 활성화됨)
   git commit -m "your message"
   # → 위반 사항 있으면 자동으로 커밋 차단됨
   ```

4. **버튼/모달 코딩 시 금지 사항**
   ```html
   <!-- ❌ 절대 이렇게 하지 마세요 -->
   <button class="btn-primary">저장</button>
   <button class="btn btn-secondary">취소</button>

   <div class="modal" id="my-modal">
       <div class="modal-content">...</div>
   </div>
   <script>
   function openModal(id) { /* ... */ }
   function closeModal(id) { /* ... */ }

   ```

## 문제 해결

### Q1. 컴포넌트 파일을 찾을 수 없어요

```
Fatal error: require_once(): Failed opening required '/var/www/html/topmkt/src/components/ui/Button.php'
```

**해결**: SRC_PATH 상수 확인

```php
// 파일 상단에 추가
define('SRC_PATH', __DIR__ . '/../src');
```

### Q2. 버튼 스타일이 적용되지 않아요

**원인**: main.css가 로드되지 않음

**해결**: header.php에 CSS 포함 확인

```html
<link rel="stylesheet" href="/assets/css/main.css">
```

### Q3. 특정 페이지에서만 다른 스타일이 필요해요

**해결**: `class` 옵션 사용

```php
<?= renderButton('특별 버튼', 'primary', 'md', ['class' => 'my-custom-class']) ?>
```

### Q4. Claude Code로 개발 시 컴포넌트 사용법

**해결**: 파일 상단 주석 및 이 가이드 문서 참고

1. 작업 시작 전 이 문서 확인
2. 파일 상단 컴포넌트 주석 확인
3. `renderButton()`, `renderModal()` 함수 사용

### Q5. 모달이 표시되지 않아요

**원인**: modal.js 스크립트 미포함 또는 CSS 로드 실패

**해결**: 필수 리소스 확인

```php
<!-- 1. Modal.php 컴포넌트 import -->
<?php require_once SRC_PATH . '/components/ui/Modal.php'; ?>

<!-- 2. modal.js 스크립트 포함 (</body> 전에) -->
<script src="/assets/js/modal.js"></script>

<!-- 3. main.css 포함 확인 (header.php) -->
<link rel="stylesheet" href="/assets/css/main.css">
```

### Q6. 모달이 열리지 않아요

**원인**: openModal 함수 호출 오류 또는 모달 ID 불일치

**해결**: 모달 ID 일치 확인 및 함수 호출 검증

```php
<!-- 모달 정의 -->
<?= renderModal('my-modal', '제목', '<p>내용</p>') ?>

<!-- 버튼에서 정확한 ID로 호출 -->
<?= renderButton('열기', 'primary', 'md', ['onclick' => 'openModal("my-modal")']) ?>
```

### Q7. 기존 모달 함수와 충돌해요

**원인**: 기존 페이지에 openModal/closeModal 함수가 이미 정의됨

**해결**: 기존 함수를 확장하거나 제거

```javascript
// 방법 1: 기존 함수 확장 (admin/users/list.php 참고)
const originalCloseModal = closeModal;
window.closeModal = function(modalId) {
    originalCloseModal(modalId);
    // 추가 로직...
};

// 방법 2: 기존 함수 완전 제거하고 modal.js 사용 (권장)
```
