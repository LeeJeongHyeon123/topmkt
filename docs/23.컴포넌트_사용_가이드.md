## SearchFilter 컴포넌트 (SearchFilter.php)

### 🎯 사용 목적

검색 및 필터링 기능을 **일관된 UI와 동작**으로 통합 관리합니다.

### 📦 불러오기

```php
<?php require_once SRC_PATH . '/components/ui/SearchFilter.php'; ?>
```

> **CSS 자동 로드**: `search-filter.css`는 `header.php`, `admin_layout.php`에서 자동 로드됨

---

### 기본 사용법

#### 1. Inline 레이아웃 (한 줄 필터)

```php
<?php
echo SearchFilter::create([
    'method' => 'JS',
    'layout' => 'inline',
    'filters' => [
        [
            'type' => 'select',
            'name' => 'status',
            'id' => 'statusFilter',
            'label' => '상태',
            'options' => [
                'all' => '전체',
                'active' => '활성',
                'inactive' => '비활성'
            ],
            'value' => 'all'
        ]
    ],
    'searchInput' => true,
    'searchPlaceholder' => '검색어를 입력하세요...',
    'onSubmit' => 'handleSearch()',
    'onReset' => 'handleReset()'
]);
?>
```

**결과**:
- 필터 + 검색창이 한 줄로 정렬
- JavaScript 콜백으로 실시간 필터링 가능

#### 2. Grid 레이아웃 (다중 필터)

```php
<?php
echo SearchFilter::create([
    'method' => 'JS',
    'layout' => 'grid-4',  // 4열 그리드
    'filters' => [
        ['type' => 'select', 'name' => 'status', 'label' => '상태', 'options' => [...]],
        ['type' => 'select', 'name' => 'role', 'label' => '권한', 'options' => [...]],
        ['type' => 'date', 'name' => 'dateFrom', 'label' => '시작일'],
        ['type' => 'date', 'name' => 'dateTo', 'label' => '종료일'],
        ['type' => 'select', 'name' => 'category', 'label' => '카테고리', 'options' => [...]],
        ['type' => 'select', 'name' => 'region', 'label' => '지역', 'options' => [...]],
        ['type' => 'select', 'name' => 'verified', 'label' => '인증', 'options' => [...]],
        ['type' => 'select', 'name' => 'sort', 'label' => '정렬', 'options' => [...]]
    ],
    'searchInput' => true,
    'searchInputId' => 'search-input',
    'submitButton' => true,
    'resetButton' => true,
    'collapsible' => true,
    'title' => '🔍 필터 및 검색',
    'onSubmit' => 'applyFilters()',
    'onReset' => 'resetFilters()'
]);
?>
```

**결과**:
- 8개 필터가 4열 그리드로 배치
- 접이식 기능으로 화면 공간 절약
- 검색창은 별도 행에 표시

#### 3. 날짜 전용 필터 (검색창 없음)

```php
<?php
echo SearchFilter::create([
    'method' => 'JS',
    'layout' => 'inline',
    'filters' => [
        ['type' => 'date', 'name' => 'startDate', 'id' => 'startDate', 'label' => '시작일'],
        ['type' => 'date', 'name' => 'endDate', 'id' => 'endDate', 'label' => '종료일']
    ],
    'searchInput' => false,  // 검색창 비활성화
    'submitButton' => true,
    'submitText' => '필터 적용',
    'resetButton' => true,
    'onSubmit' => 'applyDateFilter()',
    'onReset' => 'resetDateFilter()'
]);
?>
```

**결과**:
- 날짜 필터 2개만 표시
- 검색창 없이 깔끔한 UI

### 🔧 설정 옵션

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `method` | string | `GET` | `GET`, `POST`, `JS` (JavaScript 콜백) |
| `layout` | string | `inline` | `inline`, `grid-2`, `grid-3`, `grid-4` |
| `filters` | array | `[]` | 필터 배열 |
| `searchInput` | bool | `true` | 검색 input 표시 여부 |
| `searchInputId` | string | `''` | 검색 input 커스텀 ID |
| `searchPlaceholder` | string | `검색어를 입력하세요...` | 검색 placeholder |
| `submitButton` | bool | `true` | 제출 버튼 표시 |
| `submitText` | string | `<i class="fas fa-search"></i> 검색` | 제출 버튼 텍스트 |
| `resetButton` | bool | `true` | 리셋 버튼 표시 |
| `resetText` | string | `<i class="fas fa-undo"></i> 초기화` | 리셋 버튼 텍스트 |
| `collapsible` | bool | `false` | 접이식 기능 |
| `collapsed` | bool | `false` | 초기 접힘 상태 |
| `title` | string | `🔍 필터 및 검색` | 제목 (collapsible=true 시) |
| `onSubmit` | string | `null` | JavaScript 콜백 (method=JS 시) |
| `onReset` | string | `null` | JavaScript 리셋 콜백 |

### ⚠️ 주의사항

1. **method=JS 사용 시**: `onSubmit` 콜백 필수
2. **searchInputId 설정 시**: 기존 JavaScript와 ID 충돌 확인
3. **inline + searchInput=true**: 검색창이 필터와 한 줄에 표시됨
4. **CSS 자동 로드**: search-filter.css는 header.php, admin_layout.php에서 자동 로드

## 버튼 컴포넌트 (Button.php)

### 🎯 사용 목적

모든 버튼을 **일관된 스타일과 동작**으로 통합 관리합니다.

### 📦 불러오기

```php
<?php require_once SRC_PATH . '/components/ui/Button.php'; ?>
```

---

### 기본 사용법

#### 1. 주요 액션 버튼 (저장, 등록, 확인)

```php
<?= renderButton('저장', 'primary') ?>
<?= renderButton('등록', 'primary', 'lg') ?>
<?= renderButton('확인', 'primary', 'md', ['buttonType' => 'submit']) ?>
```

**결과**:
- 파란색 그라디언트 버튼
- 크기: md (기본), lg (큰 버튼)
- type="submit" (폼 제출용)

#### 2. 보조 액션 버튼 (취소, 목록)

```php
<?= renderButton('취소', 'secondary') ?>
<?= renderButton('목록', 'secondary', 'md', ['href' => '/lectures']) ?>
```

**결과**:
- 회색 버튼
- 링크 버튼 (href 지정 시 `<a>` 태그로 렌더링)

#### 3. 위험 액션 버튼 (삭제)

```php
<?= renderButton('삭제', 'danger', 'md', [
    'icon' => 'fas fa-trash',
    'onclick' => 'confirmDelete()'
]) ?>
```

**결과**:
- 빨간색 버튼
- 아이콘 포함
- 클릭 이벤트 연결

#### 4. 성공/경고/정보 버튼

```php
<?= renderButton('승인', 'success') ?>
<?= renderButton('경고', 'warning') ?>
<?= renderButton('상세보기', 'info') ?>
```

#### 5. 아웃라인 버튼

```php
<?= renderButton('자세히', 'outline') ?>
```

**결과**:
- 투명 배경 + 테두리만

---

### 📏 버튼 크기

| 크기 | 높이 | 용도 | 예시 |
|-----|------|------|------|
| `sm` | 36px | 작은 버튼 (테이블 액션) | `renderButton('수정', 'primary', 'sm')` |
| `md` | 44px | 기본 버튼 (대부분) | `renderButton('저장', 'primary', 'md')` |
| `lg` | 52px | 큰 버튼 (CTA) | `renderButton('시작하기', 'primary', 'lg')` |

> **접근성 보장**: 모든 크기는 최소 터치 타겟 44px 이상 (WCAG 2.1 AAA)

---

### 🎨 버튼 타입 및 색상

| 타입 | 색상 | 용도 |
|------|------|------|
| `primary` | 파란 그라디언트 (#1e88e5) | 주요 액션 |
| `secondary` | 회색 (#f5f5f5) | 보조 액션 |
| `danger` | 빨강 (#e53935) | 삭제/위험 |
| `success` | 초록 그라디언트 (#48bb78) | 성공/승인 |
| `warning` | 주황 (#F59E0B) | 경고/주의 |
| `info` | 파랑 (#3b82f6) | 정보/상세 |
| `outline` | 투명 + 테두리 | 부드러운 액션 |

**결과**:

- 복잡한 폼 입력에 적합

#### 4. 간단한 확인 모달 (헬퍼 함수)

## 문제 해결

### Q1. 컴포넌트 파일을 찾을 수 없어요

```
Fatal error: require_once(): Failed opening required '/var/www/html/topmkt/src/components/ui/Button.php'
```

**해결**: SRC_PATH 상수 확인

```php
// 파일 상단에 추가
define('SRC_PATH', __DIR__ . '/../src');
```

### Q2. 버튼 스타일이 적용되지 않아요

**원인**: main.css가 로드되지 않음

**해결**: header.php에 CSS 포함 확인

```html
<link rel="stylesheet" href="/assets/css/main.css">
```

### Q3. 특정 페이지에서만 다른 스타일이 필요해요

**해결**: `class` 옵션 사용

```php
<?= renderButton('특별 버튼', 'primary', 'md', ['class' => 'my-custom-class']) ?>
```

### Q4. Claude Code로 개발 시 컴포넌트 사용법

**해결**: 파일 상단 주석 및 이 가이드 문서 참고

1. 작업 시작 전 이 문서 확인
2. 파일 상단 컴포넌트 주석 확인
3. `renderButton()`, `renderModal()` 함수 사용

### Q5. 모달이 표시되지 않아요

**원인**: modal.js 스크립트 미포함 또는 CSS 로드 실패

**해결**: 필수 리소스 확인

```php
<!-- 1. Modal.php 컴포넌트 import -->
<?php require_once SRC_PATH . '/components/ui/Modal.php'; ?>

<!-- 2. modal.js 스크립트 포함 (</body> 전에) -->
<script src="/assets/js/modal.js"></script>

<!-- 3. main.css 포함 확인 (header.php) -->
<link rel="stylesheet" href="/assets/css/main.css">
```

### Q6. 모달이 열리지 않아요

**원인**: openModal 함수 호출 오류 또는 모달 ID 불일치

**해결**: 모달 ID 일치 확인 및 함수 호출 검증

```php
<!-- 모달 정의 -->
<?= renderModal('my-modal', '제목', '<p>내용</p>') ?>

<!-- 버튼에서 정확한 ID로 호출 -->
<?= renderButton('열기', 'primary', 'md', ['onclick' => 'openModal("my-modal")']) ?>
```

// 방법 1: 기존 함수 확장 (admin/users/list.php 참고)
const originalCloseModal = closeModal;
window.closeModal = function(modalId) {

```html
<div class="page-header">
    <div class="page-header-content">
        <div class="page-header-icon">
            <i class="fas fa-[icon]"></i>
        </div>
        <div>
            <h1 class="page-header-title">[페이지 제목]</h1>
            <p class="page-header-subtitle">[부제목/설명]</p>
        </div>
    </div>
</div>
```

### ⚠️ 주의사항

1. **헤더 수정 금지**: 각 헤더 파일을 직접 수정하지 마세요. 디자인 통일성을 위해 중앙에서 관리됩니다.
2. **색상 변경 금지**: 그라디언트 색상은 페이지별 브랜드 컬러로 고정되어 있습니다.
3. **구조 유지**: 헤더 HTML 구조(`page-header` → `page-header-content` → `page-header-icon/title/subtitle`)는 반드시 유지해야 합니다.
4. **CSS 의존성**: 헤더는 `/assets/css/main.css`의 `.page-header` 스타일에 의존합니다.
