## 13. JWT 인증 시스템

**파일:** [13.JWT_인증_시스템.md](13.JWT_인증_시스템.md) **🆕**

### 주요 내용
- JWT(JSON Web Token) 기반 인증 시스템 완전 구현
- 30일 장기 로그인 지원 (로그인 상태 유지 체크시)
- Access Token (1시간) + Refresh Token (30일) 이중 토큰 시스템
- 자동 토큰 갱신 시스템 (만료 5분 전 백그라운드 리프레시)
- HTTP-only 쿠키 기반 보안 저장
- 로그인 후 원래 페이지 자동 리다이렉션
- 모바일 친화적 설계 (컴퓨터 종료 후에도 로그인 유지)

### 핵심 정보 🆕
- **구현 완료일**: 2025년 6월
- **보안 특징**: HMAC SHA256 서명, HTTP-only 쿠키, XSS 방지
- **성능 특징**: Stateless 인증, 서버 분산 환경 지원
- **사용자 경험**: 30일 자동 로그인, 자동 토큰 갱신으로 끊김 없는 사용
- **기술 스택**: JWT Helper 클래스, AuthMiddleware, CSRF 보호 통합
- **주요 개선**: 세션 기반 → JWT 기반 전환으로 모바일 사용성 대폭 향상
