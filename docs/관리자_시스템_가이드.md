## 1. 시스템 개요

### 🎯 관리자 시스템 목적
탑마케팅 플랫폼의 관리자 시스템은 플랫폼 전반의 운영 관리, 사용자 관리, 콘텐츠 관리를 위한 종합 관리 도구입니다.

### ✅ 주요 특징
- **통합 대시보드**: 실시간 통계 및 주요 지표 모니터링
- **사용자 관리**: 일반회원, 기업회원 통합 관리
- **콘텐츠 관리**: 게시글, 댓글, 강의, 행사 관리
- **권한 기반 접근**: ROLE_ADMIN 권한자만 접근 가능
- **실시간 알림**: 긴급 처리 필요 사항 알림
- **독립적 UI**: 사용자 페이지와 완전 분리된 관리자 전용 인터페이스

### 🔄 현재 상태
- ✅ AdminController 완전 구현
- ✅ 독립적인 관리자 레이아웃
- ✅ 실시간 통계 대시보드
- ✅ 기업회원 승인/거절 시스템
- ✅ 강의 신청 관리 시스템
- ✅ 활동 로깅 시스템

## 2. 접근 권한 및 보안

### 🔒 접근 권한

#### 2.1 권한 확인 시스템
```php
// AdminController에서 권한 확인
private function checkAdminAccess() {
    if (!AuthMiddleware::isLoggedIn()) {
        header('Location: /auth/login');
        exit;
    }
    
    $userRole = AuthMiddleware::getCurrentUserRole();
    if ($userRole !== 'ROLE_ADMIN') {
        header('Location: /errors/403');
        exit;
    }
}
```

### 🛡️ 보안 조치

#### 2.3 활동 로깅
```php
// 모든 관리자 활동 자동 기록
private function logAdminActivity($action, $details = null) {
    $logData = [
        'admin_id' => AuthMiddleware::getCurrentUserId(),
        'action' => $action,
        'details' => $details,
        'ip_address' => $_SERVER['REMOTE_ADDR'],
        'user_agent' => $_SERVER['HTTP_USER_AGENT'],
        'timestamp' => date('Y-m-d H:i:s')
    ];
    
    WebLogger::info("관리자 활동", $logData);
}
```

```php
// 사용자 검색 및 필터링
public function userList() {
    $filters = [
        'status'     => $_GET['status'] ?? 'all',
        'role'       => $_GET['role'] ?? 'all',
        'search'     => $_GET['search'] ?? '',
        'date_from'  => $_GET['date_from'] ?? '',
        'date_to'    => $_GET['date_to'] ?? ''
    ];
    
    $users = User::getFilteredUsers($filters);
    return $this->render('admin/users/list', compact('users', 'filters'));
}
```

#### 4.2 사용자 상세 정보
- **기본 정보**: 닉네임, 이메일, 전화번호, 가입일
- **활동 통계**: 게시글 수, 댓글 수, 로그인 빈도
- **인증 상태**: 휴대폰 인증, 이메일 인증
- **제재 이력**: 경고, 정지, 탈퇴 이력

#### 4.3 사용자 관리 액션
```php
// 사용자 상태 변경
public function updateUserStatus($userId) {
    $status = $_POST['status']; // active, suspended, deleted
    $reason = $_POST['reason'];
    
    $result = User::updateStatus($userId, $status, $reason);
    
    if ($result) {
        $this->logAdminActivity('USER_STATUS_CHANGE', [
            'user_id' => $userId,
            'new_status' => $status,
            'reason' => $reason
        ]);
        
        // 사용자에게 알림 발송
        $this->sendUserNotification($userId, $status, $reason);
    }
    
    return ResponseHelper::json($result);
}
```

#### 5.3 승인/거절 처리
```php
// 기업인증 승인
public function approveCorporate($corporateId) {
    $adminNotes = $_POST['admin_notes'];
    
    $corporate = Corporate::find($corporateId);
    $corporate->status = 'approved';
    $corporate->approved_at = date('Y-m-d H:i:s');
    $corporate->approved_by = AuthMiddleware::getCurrentUserId();
    $corporate->admin_notes = $adminNotes;
    $corporate->save();
    
    // 사용자 권한 업데이트
    User::updateRole($corporate->user_id, 'ROLE_CORP');
    
    // 승인 SMS 발송
    $this->sendCorporateApprovalSms($corporate);
    
    $this->logAdminActivity('CORPORATE_APPROVED', [
        'corporate_id' => $corporateId,
        'company_name' => $corporate->company_name
    ]);
    
    return ResponseHelper::success('기업인증이 승인되었습니다.');
}
```

#### 10.3 권한 미들웨어
```php
class AdminMiddleware {
    public static function checkPermission($requiredRole = 'ROLE_ADMIN') {
        if (!AuthMiddleware::isLoggedIn()) {
            return false;
        }
        
        $userRole = AuthMiddleware::getCurrentUserRole();
        
        $roleHierarchy = [
            'ROLE_SUPER_ADMIN' => 3,
            'ROLE_ADMIN' => 2,
            'ROLE_MODERATOR' => 1,
            'ROLE_USER' => 0
        ];
        
        $userLevel = $roleHierarchy[$userRole] ?? 0;
        $requiredLevel = $roleHierarchy[$requiredRole] ?? 0;
        
        return $userLevel >= $requiredLevel;
    }
}
```
