**해결** (beforeinput 이벤트):
```javascript
let isDeleting = false;

phoneInput.addEventListener('beforeinput', function(e) {
    if (e.inputType === 'deleteContentBackward') {
        isDeleting = true;
    }
});

phoneInput.addEventListener('input', function(e) {
    if (isDeleting && (value.length === 7 || value.length === 3)) {
        // 하이픈 추가 방지
    }
});
```

**Playwright 테스트**:

### 🔍 근본 원인 분석

**무한 재귀 루프 발생 메커니즘**:

```javascript
// ❌ 문제 코드 (v3.90.9)
function renderChatRoomItem(roomId, roomData) {
    // ...
    if (!users[otherUserId]) {
        loadUserInfo(otherUserId).then(() => {
            renderChatRoomItem(roomId, roomData); // ← 자기 자신을 재호출!
        });
    }
}

async function loadUserInfo(userId) {
    if (!userId || users[userId]) {
        return Promise.resolve(); // ← users[userId] 있으면 early return
    }
    // API 호출...
}
```

**문제 흐름**:
1. `renderChatRoomItem(roomId, roomData)` 호출
2. `users[otherUserId]` 없으면 `loadUserInfo()` 호출
3. `loadUserInfo()` 완료 후 `renderChatRoomItem()` 재호출
4. `users[otherUserId]`는 존재하지만 `nickname`이 없음
5. `shouldRefreshProfile` 조건에 의해 다시 `loadUserInfo()` 호출 시도
6. 하지만 `loadUserInfo()`는 `users[userId]` 존재 시 즉시 `return`
7. **무한 재귀 루프 발생!** → 페이지 멈춤

### ✅ 해결 방법

**1. 재귀 호출 완전 제거**
```javascript
// ✅ 수정 후 (v3.91.0)
loadUserInfo(otherUserId).then(() => {
    // 재귀 호출 대신 DOM 직접 업데이트

        const nameEl = roomItem.querySelector('.room-name');
        const avatarEl = roomItem.querySelector('.room-avatar');

        if (nameEl) {
            const newName = users[otherUserId].nickname || '사용자';
            nameEl.textContent = newName + (isOtherParticipantInactive ? ' (종료된 대화)' : '');
        }

        if (avatarEl && users[otherUserId].profile_image) {

```

### 🔍 문제 분석 (v3.89.9 - 메타 정보 텍스트)

**원인**:
```css
/* 문제: .meta-item에 color 속성 없음 */

    display: flex;
    align-items: center;
    gap: 6px;
    /* ❌ color 속성 없음 */

/* 부모 요소의 color: inherit가 흰색 상속 유발 */

}
```

**해결**:

   - 강의 상세 페이지: 로그인 버튼 클릭 시 `preventDefault()` 하지 않도록 수정
