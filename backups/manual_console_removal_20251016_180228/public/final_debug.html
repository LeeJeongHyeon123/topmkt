🎯 최종 UI 디버깅 가이드

단계별로 따라하면 반드시 문제를 찾을 수 있습니다.

1단계: 브라우저 캐시 완전 초기화

가장 먼저 해야 할 일입니다.

Chrome/Edge:

Ctrl + Shift + Delete → "캐시된 이미지 및 파일" 체크 → "데이터 삭제"

Firefox:

Ctrl + Shift + Delete → "캐시" 체크 → "지우기"

또는 시크릿 모드:

Ctrl + Shift + N (Chrome) 또는 Ctrl + Shift + P (Firefox)

2단계: 페이지 방문 및 개발자 도구 열기

  1. https://www.topmktx.com/lectures/3 방문
  2. F12 또는 Ctrl+Shift+I로 개발자 도구 열기
  3. Console 탭에서 에러 확인
⚠️ 중요: Console에 빨간색 에러 메시지가 있으면 그것이 문제의 원인입니다!

3단계: CSS 파일 로드 확인

Network 탭에서 CSS 파일들이 제대로 로드되는지 확인:

  1. Network 탭 클릭
  2. 페이지 새로고침 (F5)
  3. CSS 필터 적용
  4. 다음 파일들이 200 OK인지 확인:
    • base.css.php
    • layout.css.php
    • buttons.css.php
    • main.css
    • loading.css
    • badges.css
    • search-filter.css
✅ 정상: 모든 파일이 200 OK, 초록색
❌ 문제: 404, 500 에러 또는 빨간색 표시

4단계: DOM 요소 존재 확인

Elements 탭에서 다음 요소들이 존재하는지 확인:

<div class="lecture-detail-container"> <div class="lecture-header"> <div class="lecture-banner"> <div class="lecture-category">🏢 컨퍼런스</div> <h1 class="lecture-title">글로벌 네트워크 마케팅 컨퍼런스 2025</h1> <div class="lecture-meta-basic"> <div class="meta-item">🟢 시작 : 2025년 08월 05일 09:00</div> </div> </div> </div> <div class="lecture-content"> <div class="lecture-main">...</div> <div class="lecture-sidebar">...</div> </div> </div>
✅ 정상: 모든 요소가 HTML에 존재
❌ 문제: 요소가 없거나 다른 구조

5단계: CSS 스타일 적용 확인

Elements 탭에서 각 요소를 클릭한 후 Computed 탭 확인:

// .lecture-banner 클릭 후 Computed 탭에서 확인 background: linear-gradient(135deg, rgb(102, 126, 234) 0%, rgb(118, 75, 162) 100%) // .lecture-title 클릭 후 Computed 탭에서 확인 font-size: 40px font-weight: 700 // .lecture-content 클릭 후 Computed 탭에서 확인 display: flex
✅ 정상: 위 스타일들이 적용됨
❌ 문제: 다른 값이 적용됨 또는 "not defined"

6단계: CSS 우선순위 분석

요소 선택 후 Styles 탭에서 CSS 규칙 확인:

// .lecture-banner의 Styles 탭에서 .lecture-banner { background: linear-gradient(135deg, #667eea 0%, #764ba2 100%) !important; color: white !important; padding: 80px 40px 40px 40px !important; /* ... */ }
⚠️ 체크사항:
- CSS 규칙이 취소선으로 그어져 있는가?
- 더 높은 우선순위의 다른 규칙이 있는가?
- !important가 제대로 적용되었는가?

7단계: JavaScript 스타일 변경 감지

Console 탭에 다음 코드 실행:

// 스타일 변경 감지 const observer = new MutationObserver((mutations) => { mutations.forEach((mutation) => { if (mutation.type === 'attributes' && mutation.attributeName === 'style') { console.log('🎭 스타일 변경:', mutation.target.className, mutation.target.getAttribute('style')); } }); }); // 강의 요소들 감시 document.querySelectorAll('[class*="lecture"]').forEach(el => { observer.observe(el, { attributes: true, attributeFilter: ['style'] }); }); console.log('👀 스타일 변경 감시 시작...');

8단계: 결과 보고

위 단계들을 수행한 후 다음 정보를 알려주세요:

📋 보고 양식:

1. 브라우저: Chrome/Firefox/Edge 버전
2. Console 에러: 있음/없음 (있으면 내용)
3. Network 상태: 모든 CSS 200 OK?
4. DOM 구조: 요소들 존재함?
5. CSS 적용: 스타일들이 적용됨?
6. 우선순위: CSS 규칙 취소선 여부
7. 스크린샷: 현재 페이지 모습
8. 기대 vs 실제: 어떻게 보여야 하는지 vs 실제로 어떻게 보이는지

9단계: 문제별 해결 방법

🚨 Console에 에러가 있으면:
→ JavaScript 에러가 CSS 적용을 막고 있을 수 있음
🚨 CSS 파일이 404면:
→ 서버 설정 문제 또는 파일 경로 문제
🚨 DOM 요소가 없으면:
→ PHP/HTML 렌더링 문제
🚨 CSS 스타일이 적용되지 않으면:
→ CSS 우선순위 문제 또는 구문 오류
🚨 스타일이 취소선으로 그어져 있으면:
→ 다른 CSS 규칙이 우선 적용됨

최종 제안

위 단계를 따라 결과를 알려주시면 정확한 원인을 파악하고 해결할 수 있습니다.
