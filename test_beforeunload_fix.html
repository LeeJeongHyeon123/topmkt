🔧 Beforeunload 이벤트 수정 테스트

✅ 수정 완료된 내용

  • 전역 변수 추가: isFormSubmitted = false
  • 성공 시 설정: 폼 제출 성공 시 isFormSubmitted = true
  • 취소 버튼: 클릭 시 isFormSubmitted = true 설정
  • 삭제 기능: 삭제 시작 시 isFormSubmitted = true 설정
  • beforeunload 개선: isFormSubmitted 체크 추가

🧪 테스트 방법

  1. 공지사항 작성 페이지로 이동
  2. 제목과 내용을 입력
  3. 작성하기 버튼 클릭
  4. 성공 알림 후 상세 페이지로 이동
  5. 예상 결과: "변경사항이 저장되지 않을 수 있습니다" 경고가 더 이상 표시되지 않음
