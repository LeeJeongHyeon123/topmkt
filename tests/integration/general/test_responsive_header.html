타겟 크기: 812×858

🎯 812×858 사이즈 테스트 영역

이 크기에서 헤더의 햄버거 메뉴가 표시되어야 합니다.

user-menu는 숨겨지고 햄버거 메뉴로 대체됩니다.

📱 반응형 브레이크포인트

  • 901px 이상: 데스크톱 모드 (user-menu 표시)
  • 481px~900px: 태블릿 모드 (햄버거 메뉴 사용) ⭐
  • 480px 이하: 작은 모바일 모드 (컴팩트 헤더)

🔧 테스트 방법

1. 브라우저 개발자 도구를 열어주세요 (F12)

2. 반응형 모드를 활성화하세요

3. 화면 크기를 812×858로 설정하세요

4. 헤더에서 햄버거 메뉴가 나타나는지 확인하세요

5. user-menu가 숨겨졌는지 확인하세요
