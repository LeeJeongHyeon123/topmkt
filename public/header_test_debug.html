📋 테스트 방법

  1. 브라우저 개발자 도구 열기 (F12)
  2. 반응형 모드 활성화
  3. 화면 크기를 812×858로 설정
  4. 메인 사이트 (/) 접속
  5. 헤더에서 햄버거 메뉴가 나타나는지 확인
  6. user-menu가 완전히 숨겨졌는지 확인
