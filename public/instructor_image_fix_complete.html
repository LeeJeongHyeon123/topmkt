💻 기술적 구현

processInstructorImages() 메서드 로직:

1. handleInstructorImageUploads()로 이미지 파일 업로드
2. lecture_instructors 테이블에서 강사 목록 조회
3. 업로드된 이미지를 강사 순서대로 매칭
4. instructor_image 필드 업데이트
5. lectures 테이블의 instructor_image도 호환성을 위해 업데이트
수정된 store() 메서드:

// 기존
$this->handleInstructorImageUploads($_FILES['instructor_images']);

// 수정
$this->processInstructorImages($eventId, $_FILES['instructor_images']);
