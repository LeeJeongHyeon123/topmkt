🔧 수정 사항 상세

1. 중복 이미지 섹션 제거

  • 문제: content-section과 info-card 두 곳에서 행사 이미지 표시
  • 해결: 사이드바의 info-card 이미지 섹션 완전 제거
  • 결과: 메인 영역의 content-section에서만 이미지 표시

2. 다중 강사 표시 시스템 구축

  • 문제: 강사 2명 등록했지만 1명만 표시됨
  • 해결: EventController에 saveMultipleInstructors() 메서드 추가
  • 해결: lecture_instructors 테이블 활용하여 다중 강사 저장
  • 해결: getEventInstructors() 메서드로 강사 정보 로드

3. 강사 이미지 표시 시스템

  • 문제: 강사 이미지가 표시되지 않음
  • 해결: lecture_instructors 테이블에 instructor_image 컬럼 추가
  • 해결: 행사 185번에 테스트 강사 이미지 추가
  • 결과: 각 강사별 이미지 정상 표시

🗄️ 데이터베이스 변경사항

테이블 구조 변경:
ALTER TABLE lecture_instructors ADD COLUMN instructor_image VARCHAR(500) NULL;
행사 185번 강사 데이터 추가:
- 강사 1: 홍길동1 (이미지: instructor-1.jpg)
- 강사 2: 홍길동2 (이미지: instructor-2.jpg)

💻 코드 변경사항

EventController.php 주요 변경:
+ saveMultipleInstructors() - 다중 강사 저장
+ getEventInstructors() - 강사 정보 조회
+ store() 메서드에서 다중 강사 처리 추가
+ getEventById()에서 강사 정보 로딩 추가
events/detail.php 주요 변경:
- 중복 이미지 섹션 (info-card) 완전 제거
+ 다중 강사 표시 로직은 기존 코드 활용
