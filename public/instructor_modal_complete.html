💻 기술적 구현 사항

1. HTML 구조

  • 강사 이미지에 onclick 이벤트 추가
  • cursor: pointer 스타일로 클릭 가능함을 표시
  • 모달 HTML 구조 추가 (instructorImageModal)

2. CSS 스타일링

  • 기존 행사 이미지 모달과 일관된 디자인
  • 행사 테마 색상(파란색 그라데이션) 적용
  • 반응형 디자인으로 모든 디바이스 지원
  • 부드러운 애니메이션 효과

3. JavaScript 기능

  • openInstructorImageModal() - 모달 열기
  • closeInstructorImageModal() - 모달 닫기
  • ESC 키 및 배경 클릭으로 모달 닫기
  • 스크롤 방지/복원 기능

🔧 코드 변경사항

🎯 사용 방법

강사 이미지 모달을 사용하는 방법:

  1. 행사 상세 페이지의 강사 정보 섹션으로 이동
  2. 강사 이미지 클릭 (마우스 커서가 포인터로 변함)
  3. 모달이 열리면서 강사 이미지가 크게 표시됨
  4. ESC 키 또는 배경 클릭으로 모달 닫기
  5. X 버튼 클릭으로도 모달 닫기 가능
